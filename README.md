# Elevator Pitch

Студиям разработки игр невыгодно содержать собственную MoCap-инфраструктуру, а выбор аутсорс студий и работа с ними превращается в производственный ад: теряются недели на ручную конвертацию файлов, проблемы с коммуникацией и ревью приводят к бесконечному потоку правок, в которых сложно ориентироваться. Платформа Animation Pipeline решает эту боль, объединяя заказчиков и студии-подрядчики MoCap в единый B2B сервис с Git-подобным сервисом версионной разработки, контроля и стандартизации записываемых анимаций. Прямые конкуренты платформы отсутствуют, так как нет сервисов, которые объединяют решения всех проблем в рамках одной инфраструктуры. Используя сервис Animation Pipeline студии получают гарантированно качественные файлы анимаций без проблем с ревью и сокращают цикл производства анимаций, а MoCap-студии получают клиентов.

# Функциональные и нефункциональные требования

### Загрузка файлов захвата

1. ФТ
- Я могу выбрать файлы на компьютере и загрузить из в проект
- Я могу видеть процентную шкалу загрузки файлов
- Я могу приостановить загрузку файлов
- Я могу прекратить загрузку файлов
- Я могу увидеть сообщение об ошибке о неподходящем формате или о превышении ограничений размера
- Я могу просмотреть список загруженных файлов
- Я могу удалить загруженный файл из списка

2. НФТ
- Наличие серверного хранилища, способного вместить терабайты данных > 3 ТБ
- Защита файлов от доступа посторонних
- Сервер должен выдерживать одновременную загрузку большого количества файлов, вплоть до 50 пользователей
- Загрузка должна работать в любом из доступных форматов

### Просмотр разных версий анимации

1. ФТ
- Я могу переключаться между ветками разработки анимации
- Я могу переключаться между разными версиями в рамках одной ветки анимации
- Я могу посмотреть дату добавления данной версии анимации
- Я могу посмотреть комментарии к данной версии анимации
- Я могу включить предпросмотр анимации
- Я могу поставить на паузу предпросмотр анимации
- Я могу перейти в режим покадрового просмотра анимации
- Я могу перейти в режим просмотра анимации в 3D-движке
- Я могу оставить комментарий к данной версии анимации
- Я могу принять данную версию анимации
- Я могу отклонить данную версию анимации

2. НФТ
- Наличие серверного хранилища для разных версий анимации
- Наличие БД для хранения метаданных к каждой версии анимации
- Быстрое переключение между версиями и ветками < 1 секунды
- Целостность и неизменяемость версий анимации и ее истории
- Предпросмотр анимации должен корректно работать в основных браузерах
- Должны проверяться права для оставления комментариев, отклонения и одобрения версии анимации
